# AppHello
📱 Apps Básicos Android
📱 Descrição

Conjunto de 3 aplicativos simples para prática de entrada de dados, cálculos e lógica.

🚀 Funcionalidades
1️⃣ Boas-vindas

Entrada: nome + idade

Saída: mensagem personalizada

2️⃣ Conversor de Temperatura

Celsius → Fahrenheit

Exibe resultado na tela

3️⃣ Lei de Ohm

Fórmula: V = R × I

Calcula:

Corrente (I)

Resistência (R)

Tensão (V)

🛠️ Tecnologias

Java / Kotlin

Android Studio

EditText, Button, TextView
